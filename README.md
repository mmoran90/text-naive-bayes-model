# Naive Bayes Text Classification: Political Speech & Tweet Analysis

This project applies Naive Bayes (NB) to explore and classify political text data for two purposes:

- Exploring a Dataset: Using NB on 2024 convention speeches to predict political affiliation (Republican or Democratic) based on speech text. The notebook guides users through NB model fitting and adjusting feature selection for better performance.

- Classifying New Data: Extending NB to classify congressional candidate tweets, comparing predictions to actual affiliations.
Future work includes comparing model accuracy using convention data from 2016, 2020, and 2024.
